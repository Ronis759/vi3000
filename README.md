# VI3000 для Android TV

Android-приложение-оболочка для сайта [vi3000.top](https://vi3000.top/). Открывает каталог в WebView и добавляет то, чего не хватает браузеру на телевизоре: управление пультом, нативный видеоплеер, корректный выход и нормальный полноэкранный режим.

Приложение не содержит видео и не является официальным клиентом сайта. Все материалы открываются с vi3000.top.

## Возможности

- **Android TV**: баннер в лаунчере, запуск с пульта, стрелки/OK/Back без мыши.
- **Нативный плеер** (ExoPlayer/Media3): HLS, DASH, MP4, MKV; поддержка Referer и cookies.
- **Настройки Lampa**: на ТВ включается режим пульта, на телефоне — сенсорный.
- **Сеть как в браузере**: запросы идут обычным путём, لذلك источники фильмов находятся так же, как в PWA. Мост `AndroidJS` остаётся только для плеера и выхода.
- Полноэкранное видео, выбор файлов, загрузки, внешние ссылки (`magnet:`, `tg:`, `mailto:` и т.п.).
- Экран ошибки с кнопкой «Повторить», сохранение cookies и состояния WebView.

## Скачать APK

1. Откройте вкладку **Releases** этого репозитория.
2. Скачайте `VI3000-*.apk` из последнего релиза.
3. Установите на приставку.

Либо скачайте APK из артефактов последнего запуска **Actions** (раздел Actions → Build APK → Artifacts).

## Проверка обновлений

Приложение раз в 6 часов тихо проверяет GitHub Releases и сравнивает версию с установленной. Если вышла новая — появляется диалог с пультом:

- **Скачать и установить** — скачать APK с прогрессом и открыть системный установщик;
- **Открыть страницу** — открыть релиз в браузере;
- **Позже** — скрыть уведомление для этой версии.

Проверить обновление вручную можно так: **переведите фокус пультом на значок настроек (шестерёнка) в верхней части окна и удерживайте кнопку OK (~0,5 секунды)**. Появится меню с пунктами «Проверить обновление» и «О приложении». Обычное короткое нажатие OK по-прежнему просто открывает настройки сайта.

Системный экран установки требует подтверждения с пульта — Android не разрешает ставить APK без участия пользователя. Если установка из неизвестных источников запрещена, приложение предложит открыть нужные настройки.

Если нет сети или GitHub недоступен, приложение работает как обычно — проверка просто пропускается.

## PWA-версия

Веб-версия лежит в папке `pwa/` и публикуется на GitHub Pages:

**https://ronis759.github.io/vi3000/**

Это полноэкранная оболочка вокруг vi3000.top: иконка на рабочем столе, режим `standalone`, поддержка пульта внутри сайта. Service worker кэширует только саму оболочку — каталог и видео всегда загружаются с vi3000.top.

PWA — дополнение к APK, а не замена. Для ТВ-приставки предпочтительнее APK: в нём нативный плеер, ТВ-баннер и более надёжная работа с пультом.

## Установка на ТВ-приставку

1. Разрешите установку из неизвестных источников: **Настройки → Безопасность → Неизвестные источники**.
2. Передайте APK на приставку удобным способом:
   - через флешку;
   - через приложение «Send files to TV»;
   - через `adb install VI3000.apk`.
3. Откройте **VI3000** в списке приложений.
4. Управляйте пультом: стрелки — навигация, OK — выбор, Back — назад/выход.

## Первый запуск: авторизация

Сайт vi3000.top перед просмотром требует привязки устройства. Если при нажатии «Дивитись» появляется окно «Для просмотра необходимо авторизоваться»:

1. Откройте в Telegram бот **[@vi3000_bot](https://t.me/vi3000_bot)**.
2. Выберите **Устройства → Добавить**.
3. Введите код, показанный на экране ТВ (или отсканируйте QR-код телефоном).
4. Вернитесь в приложение — источники фильмов появятся автоматически.

Авторизация сохраняется в cookies и DOM storage, поэтому повторять её при каждом запуске не нужно. Код одноразовый: если он пропал, нажмите «Дивитись» ещё раз, чтобы получить новый.

## Сборка вручную

Нужны JDK 17 и Android SDK 35.

```bash
./gradlew assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

Для release-сборки создайте в корне `keystore.properties`:

```properties
storeFile=keystore/vi3000-release.jks
storePassword=...
keyAlias=vi3000
keyPassword=...
```

и выполните:

```bash
./gradlew assembleRelease
```

APK появится в `app/build/outputs/apk/release/app-release.apk`.

## GitHub Actions

- `.github/workflows/android.yml` — собирает APK при каждом пуше в `main`, по тегу `v*` и вручную.
- `.github/workflows/pages.yml` — публикует PWA из папки `pwa/` на GitHub Pages.

Чтобы APK подписывался постоянным ключом, добавьте в **Settings → Secrets and variables → Actions**:

| Секрет | Значение |
| --- | --- |
| `KEYSTORE_BASE64` | keystore в base64 (`base64 -w0 keystore/vi3000-release.jks`) |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `vi3000` |
| `KEY_PASSWORD` | пароль ключа |

Если секреты не заданы, APK соберётся с debug-подписью. Такой файл устанавливается, но обновить им уже установленное приложение не получится — подпись меняется.

Релиз создаётся автоматически при пуше тега:

```bash
git tag v1.0.0
git push origin v1.0.0
```
